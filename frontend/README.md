# FarmFuture AI frontend

An English-language, self-contained preview of a crop planning experience for Texas farms. The
recommendations and scores are local demo examples; this frontend does not call the backend.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Choose a sample farm, select a goal, and
compare example crop rotations. The demo scores recalculate when the selected goal changes.

## Validation

```bash
npm run lint
npm run build
```
